    CAN2 / MCP2515 (TJA1050, 8 MHz)
    
                        
                        
                        
                        
                        
    OBD-II channel
    
                        
                        
    OBD requests use only the selected interface. If it is unavailable or in Listen-Only mode, OBD polling stays idle; there is no automatic transmit fallback.
    
                        
    Vehicle control channel
    
                        
                        
    Vehicle commands go out on the selected interface only, and only when that interface is not in Listen-Only mode. There is no automatic fallback to the other interface.
    
                        
    Learn Mode channel
    
                        
                        
    Learn Mode listens on only this interface and temporarily enforces hardware Listen-Only on it. Other CAN interfaces keep their independent mode.
    
                        
    MCP2515 shares the TFT SPI bus: SCLK 12, MOSI 11, MISO 13. Use 3.3V-compatible logic or level shifters; never connect 5V SPI signals directly to ESP32 GPIOs.
